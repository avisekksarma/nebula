    How to use this lab

    If this page loaded, the lab is already running. You started it with:

    uv run --package quasar quasar-lab

    Then open http://127.0.0.1:9000. Do not also start A/B/C yourself — this page already did (ports 8001–8003).

    1. Click a case on the left. Start with 01 Election.
    2. Press Start in the bar under the nodes.
    3. Watch A, B, C. Gold ring = the node that just moved. Then press Step.
    4. When it asks a question, pick an answer and Step — or Skip guess.
    5. Continue runs until the next question. Stop gives you the cluster back (Pause / PUT).

    Log colors: green = in the map, gold = committed, amber = not committed. Checkmarks stay in this browser so you can come back later and run 01–06 again.
